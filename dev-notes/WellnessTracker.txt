## Deployment Steps

### 1. Pre-deployment code changes
- **Environment config** — split `.env` for dev/staging/prod (MONGO_URI, JWT_SECRET, STRIPE keys, CORS origins)
- **Production build** — `vite build` outputs static files; serve with Express or Nginx
- **Helmet + rate limiting** — add `helmet`, `express-rate-limit`, `cors` with allowlist
- **Logging** — add `morgan` or `pino` for structured request logs
- **Error handling** — global error handler that doesn't leak stack traces in prod

### 2. Server setup (Hetzner/DO)
```
# On the VPS:
1. Ubuntu 24.04 LTS
2. Create non-root user, disable root SSH, enable firewall (ufw)
3. Install Node.js 22 LTS via nvm
4. Install Nginx as reverse proxy
5. Install PM2 for process management
6. Set up Let's Encrypt SSL via Certbot (or just use Cloudflare proxy)
```

### 3. Nginx config
- Proxy `/api/*` → `localhost:5000` (Express)
- Serve `/` → Vite build output (`dist/`)
- Enable gzip, caching headers for static assets

### 4. CI/CD
- **GitHub Actions** — on push to `main`: build client, SCP files to VPS, `pm2 restart`
- Or use **Coolify** (free, self-hosted PaaS on your VPS) for push-to-deploy

### 5. Stripe integration
- Add `subscription` field to User model (`free`, `plus`, `pro`)
- Create Stripe Checkout sessions for upgrades
- Webhook endpoint to handle `checkout.session.completed`, `customer.subscription.updated/deleted`
- Middleware to check tier limits (e.g., goal count, history depth)

### 6. Monitoring
- **Uptime**: [UptimeRobot](https://uptimerobot.com) (free, 50 monitors)
- **Logs**: PM2 logs + optional Loki/Grafana on the same VPS
- **Errors**: [Sentry](https://sentry.io) free tier (5K errors/mo)
